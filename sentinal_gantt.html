H1: Diseño Completo (Semana 3) Arquitectura y especificaciones finalizadas y aprobadas
H2: Infraestructura Lista (Semana 5) Cloud y servicios de autenticación configurados
H3: Backend Funcional (Semana 8) API y comunicaciones IoT operativas
H4: Frontend Base (Semana 11) Interfaz principal y dashboard completados
H5: Sistema Completo (Semana 13) Todas las funcionalidades implementadas
H6: Sistema Validado (Semana 14) Pruebas completas y bugs críticos resueltos
H7: Entrega Final (Semana 16) Presentación oficial y entrega de proyecto

CRITERIOS DE ACEPTACIÓN TÉCNICOS

  • Latencia de comunicación: ≤ 0.5 segundos
  • Tasa de actualización: ≥ 1 Hz (una medición por segundo)
  • Almacenamiento de datos: Mínimo 24 horas continuas
  • Formatos de exportación: CSV y PDF funcionales
  • Modo nocturno: Contraste ≥ 70%
  • Usabilidad: Operación básica en < 15 minutos de entrenamiento
  • Alcance de comunicación: 100m con pérdida < 5%
  • Arquitectura: Monolítica por capas (React + Python + MySQL)
  • Cloud: AWS IoT Core, Timestream, Cognito, API Gateway
  • Comunicaciones: Dual MQTT (ingesta) + WebSocket (cliente)
